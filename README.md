# DevCompass

> A next-step Kanban board designed specifically for the junior developer's journey.

## Overview
**DevCompass** is designed to bridge the gap between complex enterprise project management tools and junior developers. By stripping away traditional administrative clutter and introducing smart automation, DevCompass provides junior developers with a clean, low-friction workspace that reduces cognitive overload, speeds up onboarding, and minimizes the time senior engineers spend answering repetitive workflow questions.

This project was developed as part of the Software Engineering curriculum / portfolio project at **Holberton School (Tuwaiq Academy)**.

---

## The Problem
Junior developers often experience cognitive overload and decision paralysis when looking at traditional project management tools. They struggle with questions like:
* Where should I start?
* What is the exact next step?
* How do the workflow phases begin and end?

Traditional tools are often cluttered with complex administrative configurations, charts, and setting tabs designed for corporate managers rather than supporting a beginner's learning curve.

---

## The Solution & Core Features (Based on Project Charter)
* **Simplified Kanban Interface:** A streamlined board featuring specific columns (such as Triage, Active Coding, Testing, and Review & Merge) strictly tracking immediate engineering tasks.
* **The 'Next Up' Banner:** A dedicated UI anchor showing the single most critical task a developer should focus on next to eliminate second-guessing.
* **User Authentication & Data Persistence:** A secure login system for each student that saves team progress and the status of the cards directly in the database.
* **Rich Task Cards:** Comprehensive task cards equipped with job descriptions, self-check checklists, and Postman/cURL codes for practical experiments.
