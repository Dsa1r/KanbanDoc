# Stage 2: Project Charter & Scope Baseline — DevCompass

This directory contains the core planning, scoping, and architectural baseline established for **DevCompass** during Stage 2.

## Key Decisions & Scope Summary
* **Product Vision:** A minimalist, junior-focused Kanban board enhanced with a dynamic **'Next Up' Action Banner** to eliminate decision paralysis.
* **Scope Boundary:** 
  * *In-Scope:* A simplified Kanban interface with actionable columns (`Triage and design`, `Active Coding`, `Testing`, `Review and Merge`), the "Next Up" banner, a student login system to save task progress in the database, and rich task cards containing job descriptions, self-check checklists, and Postman/cURL code snippets.
  * *Out-of-Scope (MVP):* Complex enterprise customizations, native billing code processing, multi-language support, task addition by senior developers, and AI blocking assistant.
* **Risk Management:** Locking in the database schema and UML references early to prevent integration disconnects and variable mismatches between the frontend and backend.
