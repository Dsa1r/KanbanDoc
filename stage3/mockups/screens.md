# DevCompass - Screen Layouts and Visual Components

This document details the primary screen layouts and user interface components for the DevCompass project, designed according to the Japanese Kanban-inspired visual identity.

## Project Link
- Figma Design Folder: [Figma Project Folder](https://www.figma.com/files/team/1688443008815640431/folder/668625665?fuid=1688443007400785376)

## Screen Specifications

1. Authentication Screens (Sign up / Log in)
   - Features a deep pine gradient side panel with a subtle pattern and watermark.
   - Includes minimalist input fields with clean borders for an uncluttered authentication flow.

2. Projects Overview Page
   - Displays all active projects using structured cards with generous whitespace.
   - Provides an organized view for creating, filtering, and navigating across different workspace projects.

3. Kanban Board Page
   - Core workflow interface organizing tasks across distinct status columns (To Do, In Progress, Under Review, Done).
   - Utilizes custom status chips and stage indicators to provide clear visual task tracking.

4. Roadmap Page
   - Visualizes project milestones in a sequential node timeline.
   - Node styling dynamically reflects task states (completed, current, and upcoming) using designated theme colors.
